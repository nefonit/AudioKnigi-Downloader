# Audit follow-up — 4.12.25

## Подтверждено и исправлено

- `ActionsMixin._sidecar_metadata_matches_book`: повреждённый/нечитаемый `metadata.json` теперь возвращает `None`, что включает уже предусмотренный fallback на `history.json`. Валидный sidecar с реально отличающимися метаданными по-прежнему возвращает `False`.
- `downloader._save_book_sidecars`: `metadata.json` теперь заменяется атомарно через уникальный временный файл и `os.replace()`. При неудаче замены прежний валидный файл остаётся на месте, временный файл очищается.

## Проверено как не-баг в текущем исходнике

- `ui/settings_tab.py` не содержит `output_mode_var`, «Один M4B с главами» или «MP3 + M4B». С версии 4.12.20 UI является MP3-only.
- `ui/main_tab.py` создаёт одну кнопку `app.bulk_select_tracks_btn`; `app.select_all_tracks_btn` — совместимый алиас на тот же widget. Двух независимых кнопок «Выбрать все/Снять все» нет.
- M4B не поддерживается намеренно. Поэтому старые `.m4b` не рассматриваются как текущий формат для «Прослушать последнюю книгу» и не удаляются автоматически: приложение не должно молча удалять пользовательский legacy-файл, который больше не управляется текущей MP3-only логикой.
- `_logical_y()` fallback `widget.winfo_rooty() - self.winfo_rooty()` проверен живым Tk-тестом. Для одного и того же дочернего widget логический Y не изменялся при `yview` 0%, 65% и 30%, поскольку content-frame и descendant смещаются вместе.
