## A. Загрузка, настройки, медиаданные — 5 пунктов

1. **Исправлено — `download/book_flow.py`, Mapping-треки.** `_process_book` прежде читал индекс словаря через `getattr(value, "index", value)` и пропускал его. Теперь читает `Mapping.get("index")`; тест с двумя главами-словарями возвращает оба индекса.
2. **Исправлено — `download/source_analysis.py`, неявный `self.log`.** Для облегчённых/headless объектов `_service()` теперь передаёт `progress=getattr(self, "log", None)`; тест без `log` проходит. Основной фасад продолжает использовать `log`.
3. **Не баг — `config/settings.py`, `AppSettings.__setitem__`.** Исторический ключ `normalize_audio=False` намеренно соответствует `normalization_mode='off'`. Неизвестные ключи сохраняются ради внешних расширений, и строгая валидация их типов не заявлена в контракте.
4. **Не баг — `download/media.py`, неизвестная граница следующей главы.** Выход до EOF посреди общего файла продублировал бы все следующие главы; `SharedSourceTimelineError` — намеренная остановка небезопасной нарезки.
5. **Не баг — `download/network.py`, «припаркованные» воркеры.** Ожидание 0.1 с ограничено сроком текущего задания; очередь не пополняется, отмена учитывается. Возможна небольшая накладная нагрузка, но утечка потоков не доказана.

## B. Локализация — 4 пункта

6. **Исправлено — `download/errors.py` и `runtime_exact.json`.** Добавлены DE/EN/UK переводы `SharedSourceTimelineError`; тест проверяет каждый язык.
7. **Не баг — `i18n.py`, `runtime_prefixes.json` / `runtime_regex.json`.** Обработчик реально проверяет regex *раньше* префиксов. Это не race condition: алгоритм синхронен.
8. **Исправлено — более 12 исчезнувших глав.** Новый regex локализует русскоязычный хвост `(и ещё N)` вместе со списком глав; тесты EN/DE/UK.
9. **Не баг — дубли словарных текстов в разных каталогах.** Это не повторение JSON-ключей внутри одного объекта; резервный перевод совместим с существующими тестами. Оптимизация возможна отдельно.

## C. Очередь, анализатор, отмена — 6 пунктов

10. **Исправлено сохранением исходных данных — `services/queue_service.py`, `QueueStore.load`.** При ошибке чтения задачи старая реализация просто пропускала её. Теперь оригинальный массив задач сохраняется в отдельный файл `qt_queue.recovery-<sha256>.json` рядом с очередью до последующей записи. Неполные задачи по-прежнему не запускаются автоматически. Резервная копия создаётся детерминированно и не размножается при повторных чтениях; тест проверяет содержимое.
11. **Риск/проверить — `book_analysis_service.py`, ожидание ffprobe до 2 секунд.** Короткий bounded wait обеспечивает освобождение дочернего процесса. Не подтверждены ни утечка, ни бесконечное зависание; оптимизация требует стресс-теста на медленном сервере.
12. **Не баг — `queue_service.py`, режимы `selected` и `full_mp3`.** В текущем продукте это два поддерживаемых значения. Необъявленный будущий `m4a` не обязан сохраняться как исполняемый режим.
13. **Исправлено — `queue_service.py`, огромная обложка в base64.** Добавлен лимит длины ДО декодирования и повторная проверка длины bytes. Увеличенный payload отклоняется без декодирования.
14. **Риск/проверить — опции провайдеров (`adapters.py`, `SourceAnalysisMixin`).** Существуют отдельные пути вызова общего анализатора; соответствие конкретным пользовательским настройкам требует интеграционного теста. Универсально менять дефолты небезопасно.
15. **Риск/проверить — `audioknigi_search.py`, отмена уже запущенных future.** `future.cancel()` не останавливает исполняющийся поток Python; это известная особенность Executor. Скорость отмены зависит от внутренних таймаутов и `cancel_event`; полной мгновенной остановки не гарантировано.

## D. Модели, сеть, шаблоны — 8 пунктов

16. **Не баг — `models.py`, `MappingDataclass` и `dataclass(slots=True)`.** В классе `MappingDataclass` присутствует `__slots__ = ()`. Создание `Track` и `Book` работает; задекларированные атрибуты можно менять. Непредусмотренные атрибуты намеренно запрещены.
17. **Не доказано — `download_engine.py`, `ui(func)`.** Это headless-путь с документированным прямым выполнением необязательных callback. Конкретного Qt-колбэка, вызываемого здесь из неправильного потока, отчёт не приводит.
18. **Не баг — `download_engine.py`, retain исходника при совпадении имени.** `_retained_full_source_path` явно создаёт альтернативное имя при `candidate == target`. Утверждение о неизбежной потере исходника/«вечном» временном файле опускает этот guard.
19. **Риск/проверить — `network_dns.py`, CNAME и DoH.** CNAME-цепочки могут умножить задержку; есть ограниченные таймауты и auto-fallback. Это возможная проблема скорости на заблокированных сетях, не доказанный deadlock.
20. **Не доказано — `network_dns.py`, прокси `socketserver`.** Закрытие клиентского сокета управляется жизненным циклом `BaseRequestHandler`/TCPServer. Накопление CLOSE_WAIT без воспроизведения не подтверждено.
21. **Не баг — `core.py`, cookie-domain `.example.org`.** Ведущая точка валидна для доменных cookies; безусловное `lstrip('.')` может изменить семантику. Нет подтверждённой ошибки Playwright.
22. **Риск/проверить — `poleknig.py`, HTTP-запрос кандидатов после отмены.** Непосредственно `_candidate_detail_variant` не принимает `cancel_event`; уже начатый HTTP-запрос может завершаться только по таймауту. Нужен отдельный сетевой сценарий.
23. **Исправлено — `templates.py`, повтор номера главы.** Имя `01.mp3` при шаблоне `{Track_Number}. {Track_Title}` больше не становится `01. 01.mp3`. Сначала удаляется аудиорасширение из значения титула; голый номер не повторяется. Оба шаблона покрыты тестами.
