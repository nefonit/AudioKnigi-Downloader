# Audit — Qt Migration Phase 11

## Основание

Первая реальная Windows/NVDA acceptance-сессия для Phase 10 прошла автоматические gates и 8/14 ручных пунктов. FAIL были отмечены для ComboBox, очереди, истории, настроек, плеера и модальных окон. JAWS-сессия не началась: пользователь прервал runner на приглашении Enter.

## Изменения

1. ComboBox: добавлена нативная QAccessibleAnnouncementEvent-озвучка подсвеченного и выбранного значения через Qt signals.
2. Очередь: вертикальная навигация читает сводку всей задачи (книга, статус, приоритет, попытки, части, ошибка); действия динамически включаются по состоянию выбранной задачи.
3. История: название-ячейка содержит доступную сводку всей строки; действия выбора и экспорт/очистка имеют корректные enabled states.
4. Настройки: QScrollArea wrapper имеет NoFocus, чтобы Tab переходил сразу по реальным элементам формы.
5. Плеер: позиция публикуется и объявляется в секундах, громкость — в процентах, скорость — как множитель.
6. Модальные окна: явный ApplicationModal + setModal(True); No — безопасная Escape-кнопка для вопросов.
7. Acceptance runner: повторяет только непройденные пункты для того же hash, сохраняет комментарий к FAIL, поддерживает --reader nvda/jaws/both и --retest-all, Ctrl+C сохраняет отчёт без traceback.

## Гарантии

- Tk launcher не удалён и не изменён.
- FocusIn/eventFilter-слой не возвращён.
- Пересборка создаёт новый SHA-256, поэтому старые ручные approvals не переносятся на новый EXE.
- Финальная promotion по-прежнему требует PASS всех пунктов NVDA и JAWS для точного EXE hash.
