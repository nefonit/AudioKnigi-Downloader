# Аудит восстановления истории проекта — 2026-09-05

## Цель

Собрать в одном мастер-проекте актуальную 4.12.31 и максимально полную доступную историю тестов, аудитов, документации и сборочных инструкций из прежних релизов/чатов.

## Методика

1. За основу взят каталогизированный проект 4.12.31.
2. Исторические ZIP-релизы из ChatGPT Library материализованы локально.
3. Из каждого ZIP отобраны тесты, аудиты, текстовая документация и сборочные/requirements-файлы.
4. Содержимое дедуплицировано по SHA-256, а не только по имени.
5. Файл, уже существующий в 4.12.31 байт-в-байт, не копируется повторно — индекс указывает на текущую копию.
6. Старые уникальные варианты сохраняются в `history/variants/`; исторические `.py`-тесты получают только дополнительный архивный суффикс, их байты не меняются.
