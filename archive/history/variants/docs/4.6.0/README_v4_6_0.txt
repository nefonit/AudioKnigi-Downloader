AudioKnigi Downloader 4.6.0 — User Friendly Edition
======================================================

ЧТО ГЛАВНОЕ В 4.6.0
--------------------

Версия 4.6.0 сохраняет технический движок 4.5.0, но делает интерфейс понятным
человеку, который не обязан знать термины FFmpeg, Range, loudnorm или ID3.

1. ПРОСТОЙ РЕЖИМ — ПО УМОЛЧАНИЮ

На экране остаются:
- поле ссылки;
- понятный выбор качества;
- большая кнопка «СКАЧАТЬ КНИГУ»;
- понятный статус;
- индикатор выполнения.

Технические вкладки скрыты. В любой момент сверху можно выбрать
«Расширенный» режим и получить весь интерфейс 4.5.0.

2. ПОНЯТНЫЕ ПРЕСЕТЫ КАЧЕСТВА

🎧 Стандартное — оригинальное качество
   Быстрая обработка, оригинальный MP3 без лишнего перекодирования.

📱 Для телефона — меньше размер
   Сжатие в 64 kbps mono для экономии памяти.

🔊 Выравнять громкость
   Качественная двухпроходная нормализация для тихих/неоднородных записей.

3. ПОНЯТНЫЕ СТАТУСЫ

В простом режиме технические коды не показываются. Примеры:
- 🔵 Проверяем книгу
- 🟡 Скачиваем книгу
- 🔵 Собираем главы книги
- 🔵 Выравниваем громкость
- 🟢 Готово к прослушиванию
- 🔴 Что-то пошло не так

4. ДРУЖЕЛЮБНЫЕ НАСТРОЙКИ

Вместо технических названий используются формулировки:
- «Скорость загрузки»
- «Добавлять обложку и автора прямо в аудиофайлы»
- «Скрыть техническую информацию»
- «Резервный режим обхода защиты сайта»
- «Один M4B с главами»
- «Ограничение скорости»

Точные 1/2/4/8 соединений и пороги Auto-Chunker остаются в блоке
«Тонкая настройка — можно не менять».

5. TOOLTIP-ПОДСКАЗКИ

При наведении на настройки появляется короткое объяснение человеческим языком.
Например, для M4B объясняется, что это один файл с переключением по главам,
а для ограничения скорости — что оно оставляет интернет другим устройствам.

6. БЫСТРЫЙ СТАРТ ИЗ БУФЕРА ОБМЕНА

Если пользователь скопировал ссылку audioknigi.com.ua в браузере и вернулся
в программу, 4.6.0 может предложить:

«Найдена ссылка на аудиокнигу. Скачать эту книгу?»

Функцию можно отключить в настройках.

7. ПОСЛЕ СКАЧИВАНИЯ

В простом режиме появляется отдельная панель:
- «Открыть папку с книгой»
- «Слушать»

Для MP3 кнопка «Слушать» запускает встроенный плеер. Для M4B без MP3
используется системный проигрыватель Windows.

8. ВСЕ ВОЗМОЖНОСТИ 4.5.0 СОХРАНЕНЫ

- Requests-first / Playwright fallback
- Smart Cookie / Session Persistence
- Auto-Chunker Range 2/4/8
- Token Bucket Bandwidth Limiter
- скорость и ETA
- проверка MP3
- Smart Format Match
- Two-pass loudnorm
- MP3 / M4B / MP3+M4B
- M4B главы, теги и обложки
- очередь / пауза / повторы / приоритет
- Drag-and-Drop
- поиск
- история и экспорт
- резервные копии
- Audiobookshelf
- шаблоны путей
- системный трей
- CI/CD GitHub Actions
