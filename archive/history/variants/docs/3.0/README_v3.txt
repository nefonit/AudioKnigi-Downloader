AudioKnigi Downloader 3.0

УСТАНОВКА ДЛЯ ЗАПУСКА ИЗ PYTHON

1. Открой PowerShell в папке с файлами.
2. Выполни:
   py -m pip install -r requirements.txt
   py -m playwright install chromium
3. Запуск:
   py audioknigi_gui_v3_0.py

ЧТО ДОБАВЛЕНО В 3.0

1. Кнопка отмены.
2. Продолжение недокачанного .part через HTTP Range.
3. Выбор отдельных частей.
4. Большая кнопка «СКАЧАТЬ КНИГУ».
5. Обложка и информация о книге.
6. ID3-теги и обложка внутри MP3 (если установлен mutagen).
7. Очередь нескольких книг.
8. Масштаб интерфейса, горячие клавиши и управление списком клавиатурой.
9. История загрузок.
10. build_exe.bat для сборки Windows EXE.
