AudioKnigi Downloader 4.6.1 — Visual Refresh
================================================

Что изменилось визуально
------------------------

• Новый фирменный логотип: книга + наушники + стрелка загрузки.
• Логотип используется в окне программы, EXE, системном трее и будущей установке.
• Новый тёмно-синий интерфейс в стиле современного Windows-приложения.
• Переключатель «Простой / Расширенный» оформлен отдельными крупными кнопками.
• Главный экран переработан в формате dashboard:
  - большое поле ссылки;
  - большая кнопка «СКАЧАТЬ КНИГУ»;
  - три визуальные карточки качества;
  - дружелюбный статус и прогресс;
  - крупные действия после завершения.
• Правая панель:
  - Очередь;
  - История;
  - Настройки;
  - Помощь.
• Понятные визуальные статусы:
  - зелёный — готово;
  - жёлтый — скачивание;
  - синий — обработка;
  - красный — ошибка.
• Сохранены Drag-and-Drop и быстрый старт из буфера обмена.

Карточки качества
-----------------

🎧 Стандартное
Оригинальное качество без лишней обработки.

📱 Для телефона
Меньший размер файла.

🔊 Выравнять громкость
Помогает тихим книгам и записям с разной громкостью.

Запуск из Python
----------------

py -m pip install -r requirements_v4_6_1.txt
py -m playwright install chromium
py audioknigi_gui_v4_6_1.py

Сборка EXE
----------

build_exe_v4_6_1.bat

PyInstaller автоматически использует:

assets/app_icon.ico

и включает папку assets внутрь EXE.
