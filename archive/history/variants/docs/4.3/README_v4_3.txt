AudioKnigi Downloader 4.3
=========================

ВАЖНО
-----
Версия 4.3 модульная. Не вынимайте один audioknigi_gui_v4_3.py из папки:
рядом должна оставаться папка audioknigi_v43.

ЗАПУСК
------
1. Распакуйте ZIP полностью.
2. Откройте PowerShell в папке AudioKnigi_Downloader_v4_3.
3. Выполните:

   py -m pip install -r requirements_v4_3.txt
   py -m playwright install chromium

4. Запуск:

   py audioknigi_gui_v4_3.py

FFmpeg и ffprobe должны быть доступны в PATH.

ЧТО НОВОГО В 4.3
-----------------

1. Сегментированная загрузка HTTP Range
   - 1 / 2 / 4 / 8 сегментов в настройках.
   - Включается только если сервер подтверждает HTTP 206.
   - Маленькие файлы скачиваются обычным способом.
   - Недокачанные сегменты сохраняются и могут продолжаться.
   - После загрузки сегменты объединяются и проверяется итоговый размер.

2. Скорость и ETA
   - Скорость рассчитывается по скользящему окну последних ~5 секунд.
   - Показывается суммарная скорость всех сегментов.
   - Показывается примерное оставшееся время.

3. Ограничение скорости
   - Ползунок 0-100 МБ/с.
   - 0 = без ограничения.
   - Лимит общий на все сегменты и параллельные загрузки.
   - Можно менять во время загрузки.

4. M4B с главами
   Настройка "Результат":
   - mp3  = отдельные MP3;
   - m4b  = один M4B/AAC с главами;
   - both = MP3 + M4B.

   Главы записываются через FFmpeg FFMETADATA.

5. Нормализация громкости
   Опция FFmpeg loudnorm:
   I=-16, LRA=11, TP=-1.5.

6. Сжатие / перекодирование
   Профили:
   - copy          — MP3 без перекодирования, если loudnorm выключен;
   - 64k_mono      — 64 кбит/с mono;
   - 96k_mono      — 96 кбит/с mono;
   - 128k_stereo   — 128 кбит/с stereo.

   M4B всегда кодируется AAC.

7. Системный трей Windows
   - При активной очереди сворачивание окна может убрать программу в трей.
   - В трее есть "Показать" и "Выход".
   - Уведомление о завершении очереди используется вместе с tray/Windows notification.

8. CustomTkinter
   Основные кнопки, поля, вкладки, настройки, прогресс и панели переведены на
   CustomTkinter. Таблицы оставлены на ttk.Treeview, потому что это нативный
   табличный виджет и он лучше подходит для больших списков.

9. Встроенный поиск
   Отдельная вкладка "Поиск" ищет книги на AudioKnigi.com.ua.
   Двойной щелчок по результату переносит ссылку в приложение и запускает анализ.

10. Dataclasses
   Book, Track и QueueItem теперь типизированные dataclass-модели.
   Для плавной миграции они временно поддерживают dict-подобный доступ,
   поэтому старые проверенные части логики не пришлось переписывать целиком.

ПРОВЕРКИ
--------
Базовая проверка:
   py selftest_v4_3.py

Проверка создания интерфейса:
   py ui_smoketest_v4_3.py

Проверка FFmpeg/M4B на локальном тестовом звуке:
   py audio_smoketest_v4_3.py

СБОРКА EXE
----------
Запустите:
   build_exe_v4_3.bat

После успешной сборки:
   dist\AudioKnigiDownloader\AudioKnigiDownloader.exe

ЛОКАЛЬНЫЙ ТЕСТ RANGE
--------------------

Без подключения к audioknigi.com.ua можно проверить сегментированную загрузку:

   py range_smoketest_v4_3.py

Успешный результат:

   RANGE SMOKETEST: OK
