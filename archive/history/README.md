# Исторический архив AudioKnigi Downloader

Эта папка создана после инвентаризации доступной ChatGPT Library по проекту AudioKnigi Downloader.

## Как пользоваться

- Актуальный код, тесты, документация и аудиты находятся в обычных каталогах проекта (`audioknigi/`, `tests/`, `docs/`, `audits/`).
- `history/variants/` содержит только уникальные исторические варианты файлов, которых **нет в точности** в текущем проекте.
- Исторические Python-тесты имеют дополнительный суффикс `.history`, чтобы `pytest` не запускал тесты старых версий против кода 4.12.31. Содержимое файла при этом сохранено без изменений.
- `HISTORICAL_FILE_INDEX.csv` показывает каждое появление файла в каждом исследованном релизе и указывает, где находится его каноническая копия.
- `SOURCE_ARCHIVES.csv` — реестр исследованных исторических ZIP-релизов с SHA-256.
- `UNIQUE_HISTORICAL_VARIANTS.csv` — компактный список реально сохранённых старых вариантов.

## Объём инвентаризации

- Исследовано исторических ZIP-релизов: **107**.
- Найдено релевантных появлений тестов/аудитов/документации/сборочной документации: **9423**.
- Уникальных содержаний среди них: **626**.
- Уникальных исторических содержаний, которых нет байт-в-байт в текущем проекте: **456**.

По категориям сохранено старых уникальных вариантов: docs: 217, release: 39, tests: 200.

## Граница гарантии

Это максимально полный архив из файлов и релизов, которые были доступны через ChatGPT Library и текущую беседу на момент инвентаризации. Если старый чат или его файл был удалён и больше не доступен в Library, технически восстановить его из отсутствующего источника невозможно. Поэтому формулировка — «максимально полный из доступной истории», а не доказательство существования каждого когда-либо созданного файла.
