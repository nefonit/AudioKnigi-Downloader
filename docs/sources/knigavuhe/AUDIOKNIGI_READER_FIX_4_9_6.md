# AudioKnigi Downloader 4.9.6 — reader column fix

## Исправлено

На `audioknigi.com.ua` поле «Чтец» в поиске раньше заполнялось только для групп, где уже было найдено несколько страниц одной книги. У книги с единственной найденной озвучкой дополнительное чтение страницы не выполнялось, поэтому колонка оставалась пустой.

В 4.9.6 каждая найденная страница `audioknigi.com.ua` уточняется перед группировкой. Из страницы извлекаются название, автор и исполнитель. Затем одинаковые произведения объединяются по `Название + Автор`, а все найденные исполнители сохраняются как варианты озвучки.

Запросы метаданных выполняются параллельно, до 8 одновременно. Ошибка одной страницы не прерывает общий поиск.
