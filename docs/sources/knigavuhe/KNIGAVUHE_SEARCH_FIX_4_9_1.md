# Knigavuhe search results fix — 4.9.1

Исправлено отображение результатов поиска `knigavuhe.org`.

- служебные ссылки вида `/book/<slug>/#comments_block` больше не считаются отдельными книгами;
- ссылки результатов канонизируются до `https://knigavuhe.org/book/<slug>/` без fragment/query;
- жанры, авторы, исполнители и счётчики комментариев не используются как название книги;
- HTML-парсер ссылок использует стек `<a>`, поэтому вложенные/сложные карточки не перезаписывают название книги;
- видимый текст основной ссылки книги имеет приоритет над `aria-label`, `title` и `img alt`;
- добавлены regression-тесты для реальной проблемы с `#comments_block`.
