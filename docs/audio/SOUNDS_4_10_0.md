# AudioKnigi Downloader 4.10.0 — звуки событий

Добавлены три предоставленных пользователем звука:

- `assets/sounds/download_in_progress.mp3` — один раз при начале фактического скачивания;
- `assets/sounds/download_complete.mp3` — после успешного завершения;
- `assets/sounds/error.mp3` — при ошибке операции.

## Поведение

- Звук процесса не зацикливается.
- Для одиночной книги, отдельной части и полного MP3: старт → завершение/ошибка.
- Для очереди: один старт в начале всей очереди → один итоговый звук после всей очереди. Если есть хотя бы одна ошибка, используется звук ошибки.
- Отмена пользователем не считается ошибкой и отдельного звука не воспроизводит.
- Неожиданные ошибки Tkinter/фонового потока также сопровождаются звуком ошибки.

## Настройки

В разделе **Настройки → Звуки программы** доступны:

- переключатель звуков событий;
- громкость 0–100%;
- кнопка «Проверить» (воспроизводит звук успешного завершения).

Настройки сохраняются как `event_sounds_enabled` и `event_sound_volume`.

## Архитектура

`EventSoundManager` использует `pygame.mixer.Sound` на выделенном mixer-канале. Встроенный плеер книги продолжает использовать `pygame.mixer.music`, поэтому звуки интерфейса не подменяют текущую аудиокнигу. Инициализация аудиоустройства выполняется лениво только при первом звуке; сбой звуковой подсистемы не мешает скачиванию.

PyInstaller уже добавляет весь каталог `assets`, поэтому отдельное правило упаковки для звуков не требуется.
