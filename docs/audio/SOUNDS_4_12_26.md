# AudioKnigi Downloader 4.12.26 — полный аудит звуков событий

## Проверено

В `assets/sounds/` находятся 17 русских голосовых MP3 и 17 английских вариантов. Все 34 файла успешно разбираются как MP3 и имеют ненулевую длительность.

### Голосовые события

1. `download_start` — начало загрузки.
2. `download_complete` — успешное завершение.
3. `error` — ошибка загрузки/анализа/плеера/дискового preflight.
4. `link_pasted` — ссылка вставлена.
5. `queue_item_added` — книга добавлена в очередь.
6. `search_complete` — поиск завершён с результатами.
7. `queue_complete` — очередь завершена без ошибок.
8. `queue_started` — очередь запущена.
9. `download_cancelled` — загрузка/очередь отменена.
10. `download_resumed` — очередь продолжена.
11. `download_paused` — очередь приостановлена.
12. `book_not_found` — книга/результат не найден.
13. `book_found` — книга проанализирована и найдена.
14. `recovery_started` — начато восстановление незавершённой загрузки.
15. `files_already_downloaded` — точный дубликат уже скачанной книги.
16. `narration_changed` — выбрана другая озвучка.
17. `update_available` — файл подготовлен, но автоматического runtime-триггера пока нет, потому что приложение не содержит механизма проверки обновлений.

## Системные Windows-события

- `app_ready` — программа готова после onboarding/startup.
- `attention` — обязательное поле ввода пустое и открыт пользовательский modal.
- `completed_files_missing` — ранее готовая книга удалена с диска и элемент очереди возвращён в «Ожидает».

## Windows fallback

Для каждого голосового события задан соответствующий `winsound.MessageBeep` fallback. Если pygame не инициализируется, аудиоустройство недоступно или MP3 отсутствует/не читается, важное событие всё равно получает системный Windows-сигнал. Ошибка звуков не влияет на скачивание.

Системные звуки используют системную схему и громкость Windows. Ползунок «Громкость звуков» регулирует только встроенные голосовые MP3. Общий переключатель «Воспроизводить звуки событий» отключает оба типа подсказок.

## Дополнительные закрытые пробелы

- Полный отказ поисковых провайдеров теперь вызывает `error`.
- Ошибки встроенного/внешнего мини-плеера теперь вызывают `error`.
- Невозможность определить свободное место или недостаток места на диске теперь вызывают `error` ещё до запуска download worker.

## Проверка в интерфейсе

В **Настройки → Звуки программы**:
- **Голосовой** — проверяет ваш `download_complete.mp3` с текущей громкостью программы.
- **Системный** — проверяет Windows system sound; его громкость задаётся средствами Windows.
