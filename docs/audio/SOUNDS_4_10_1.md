# AudioKnigi Downloader 4.10.1 — расширенные звуковые подсказки

Версия 4.10.1 добавляет десять новых коротких голосовых подсказок к трем звукам 4.10.0.

## События

- `link_pasted` — «Ссылка вставлена».
- `queue_item_added` — «Книга добавлена в очередь».
- `search_complete` — «Поиск завершён».
- `queue_started` — «Очередь запущена».
- `queue_complete` — «Очередь завершена».
- `download_paused` — «Загрузка приостановлена».
- `download_resumed` — «Загрузка продолжена».
- `download_cancelled` — «Загрузка отменена».
- `book_found` — «Книга найдена».
- `book_not_found` — «Книга не найдена».
- Сохраняются звуки `download_start`, `download_complete` и `error` из 4.10.0.

## Поведение

- Все звуки используют тот же отдельный `pygame.mixer.Sound` канал и не заменяют файл во встроенном мини-плеере.
- Новый звук прерывает предыдущую короткую подсказку, чтобы фразы не накладывались друг на друга.
- При автоматическом сценарии «анализ → скачать» звук «Книга найдена» пропускается: сразу звучит сигнал начала скачивания.
- Для поиска без результатов используется «Книга не найдена»; для успешного поиска с результатами — «Поиск завершён».
- Очередь использует собственные «Очередь запущена/завершена», а не общие звуки начала/завершения одной книги.
- Если очередь завершилась с ошибками, звучит «Произошла ошибка», а не «Очередь завершена».
- Пауза очереди озвучивается только когда она фактически остановилась между книгами; «Загрузка продолжена» — когда ожидание действительно снято.
- Настройки включения и громкости остаются общими для всех звуков программы.
