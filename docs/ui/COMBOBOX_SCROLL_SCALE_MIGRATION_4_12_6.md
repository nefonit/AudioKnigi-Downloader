# AudioKnigi Downloader 4.12.6

## Масштаб

При первом запуске 4.12.6 профиль без маркера миграции проверяется один раз. Если в старом `settings.json` осталось `"scale": 125`, значение меняется на `100`, а в настройки записывается маркер `ui_scale_default_100_migrated`. После этого любое значение масштаба, выбранное пользователем вручную, сохраняется как обычно, включая 125%.

## Выпадающие списки и колесо мыши

Открытый `ttk.Combobox` по-прежнему закрывается при начале прокрутки. При закрытии подавляется только кратковременный `FocusIn`, который раньше мог автоматически прокрутить страницу к самому полю и создавал эффект «всегда вверх». Исходное событие колеса затем передаётся `CTkScrollableFrame`, содержащему список, без изменения знака `delta`/Button-4/Button-5.
