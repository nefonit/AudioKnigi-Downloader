# AudioKnigi Downloader 4.12.7 — simple-mode folder picker

- The **Изменить** button in simple mode, Step 3, now opens the native folder chooser directly.
- Selecting a folder updates the shared save-folder value immediately, so simple and advanced modes stay synchronized.
- The selection is persisted through the existing settings save path.
- The button no longer redirects users to the advanced Settings tab.
- Keyboard activation remains available through the app's accessibility helper.
