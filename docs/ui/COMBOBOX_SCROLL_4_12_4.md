# AudioKnigi Downloader 4.12.4 — Combobox Scroll Guard

Исправлена проблема native `ttk.Combobox` на прокручиваемых страницах настроек: открытый выпадающий список создаётся Tk как отдельное popdown-окно и раньше мог оставаться на старых экранных координатах, когда пользователь прокручивал основную страницу колесом мыши. В результате список визуально «прилипал» и накладывался на другие элементы.

В 4.12.4 перед wheel-прокруткой программа явно выполняет `ttk::combobox::Unpost` для открытых Combobox. Пассивный глобальный обработчик не блокирует само колесо, поэтому после закрытия списка страница продолжает прокручиваться как обычно. Такое же закрытие выполняется перед перемещением длинной страницы вертикальной полосой прокрутки.

Решение сохраняет native ttk-виджеты, клавиатурную навигацию и совместимость с NVDA/JAWS/Prismatoid.
