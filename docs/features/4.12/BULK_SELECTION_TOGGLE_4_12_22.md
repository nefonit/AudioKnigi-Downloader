# 4.12.22 — One Toggle Bulk Selection Button

The advanced **Книга** tab now uses one state-aware bulk-selection button above the parts table instead of two separate controls.

- All parts selected -> **Снять все**.
- Any part not selected -> **Выбрать все**.
- Pressing **Снять все** clears every part and changes the same button to **Выбрать все**.
- Pressing **Выбрать все** selects every part and changes the same button to **Снять все**.
- Manually toggling one part also synchronizes the button text automatically.
- The screen-reader accessible name follows the current action.
