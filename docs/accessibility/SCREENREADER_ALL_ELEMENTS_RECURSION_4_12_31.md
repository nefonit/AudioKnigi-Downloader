# NVDA / JAWS: управление всеми элементами — 4.12.31

## Редакторы

На Windows приложение дополнительно наблюдает физическую команду `Insert+Up`, не блокируя стандартный жест NVDA/JAWS. Если скринридер сам забирает эту комбинацию до Tk, приложение всё равно получает уведомление через Windows low-level keyboard hook и затем произносит фактическое значение текущего редактируемого поля через Prism.

## Выпадающие списки

Когда фокус находится на списке:

- `Alt+Down`, `F4`, `Enter` или `Space` — открыть;
- `Up` / `Down` — двигаться по вариантам;
- `Enter` — подтвердить;
- `Escape` — закрыть.

Для списка вариантов озвучки скринридер получает текущее значение, состояние «открыт/закрыт», количество вариантов и инструкцию управления. При движении стрелками приложение дополнительно сообщает текущий вариант.

## Общие подсказки

AccessibilityManager автоматически добавляет инструкции к фокусируемым стандартным элементам: полям, кнопкам, флажкам, переключателям, ползункам, таблицам, вкладкам, спискам и Text-полям. Поэтому новый стандартный ttk/Tk control не должен оставаться без базовой клавиатурной подсказки.

## Диагностика

В `app.log` полезны строки:

- `ACCESSIBILITY UIA` — статус Windows UI Automation (`tk-uia`);
- `ACCESSIBILITY KEYBOARD HOOK` — статус observer для `Insert+Up`;
- `SCREEN READER GESTURE` — получение и доставка жеста;
- `SCREEN READER READ LINE` — фактически прочитанное значение;
- `ACCESSIBILITY COMBOBOX` — состояние open/closed/navigation;
- `ACCESSIBILITY FOCUS` — семантическое описание элемента при фокусе;
- `TK RECURSION GUARD` — перехваченная recursion emergency.

## Защита Tk focus callbacks

`FocusIn` больше не выполняет визуальную геометрию, регистрацию control или принудительную смену фокуса синхронно. Глобальный callback только запоминает последний widget и ставит один `after(0)`. Если за это время приходит ещё много FocusIn, они схлопываются в тот же pending callback.

В focus paths запрещены `update()` и `update_idletasks()`, поскольку они создают вложенный Tk event loop и на Windows Tk 8.6 могут повторно войти в `tkinter._substitute`. Автопрокрутка длинных `CTkScrollableFrame` тоже coalesced и выполняется через один `after(0)`.

Если Tk всё же сообщает `RecursionError`, аварийная ветка не вызывает Tcl/Tk вообще: не использует `after/after_idle`, messagebox, focus API или полный traceback formatter. Она временно отключает accessibility focus processing и сохраняет короткий диагностический статус в памяти. Regression stress генерирует 1 500 FocusIn подряд.
