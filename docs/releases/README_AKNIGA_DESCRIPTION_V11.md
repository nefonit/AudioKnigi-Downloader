# Akniga.org: точное описание аудиокниги (V11)

Основа: AudioKnigi Downloader 4.12.42, версия V10.

Исправлено извлечение описания со страницы книги Akniga.org:

- Извлекается текст именно из `.description__article-main`, если он содержит подпись «Описание».
- Вложенная подпись `.content__main__book--item--caption` исключается из описания.
- Надпись «Входит в подборку ... N аудиокниг» исключается из других HTML-полей и запасного метаописания.
- Остальные источники, загрузчик HLS и сетевая маршрутизация не изменены.

Проверка: https://akniga.org/kozhin-oleg-snegurochka

Ожидаемое описание:

Рассказ-победитель первого в истории DARKER литературного конкурса «Чёртова дюжина». Этнографическая экспедиция попадает в полузаброшенную деревню Маррь, связанную с первыми упоминаниями легенды о Снегурочке. Но реальность может оказаться гораздо страшнее привычной всем сказки…

Производственный сайт/Windows GUI необходимо проверить отдельно. Тесты включают пользовательский пример HTML с блоком подборки перед реальным описанием.
