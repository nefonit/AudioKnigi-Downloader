# Дополнительные источники — экспериментальная сборка (31.10.2026)

Основной проект: AudioKnigi Downloader 4.12.42 / Round90. Исходная база: последняя экспериментальная Parallel HLS версия.

## Источники

- **Уже существовавшие:** `audioknigi.com.ua`, `knigavuhe.org`, `poleknig.com`, `akniga.org` (Akniga поддерживается только по прямой ссылке, поиск не реализован).
- **Добавленные:** `izib.uk`, `yakniga.org`, `uknig.com`, `archive.org/details/...` (только коллекция LibriVox).
- **Bookmate / Яндекс Книги** присутствует в предоставленном проекте AudioBookPlayer, но **не перенесён в загрузчик**: для его приватных аудиоплейлистов авторизация и права на сохранение требуют отдельного согласованного сценария. Не добавлено извлечение токенов, обход DRM или скачивание лицензионных материалов.

## Изменения

- `audioknigi/providers/extra_sources.py`: новые адаптеры анализа и поиска без новой фоновой очереди.
- `audioknigi/sources.py`: строгое распознавание доменов и URL страниц книг; ссылки с похожими хостами не принимаются.
- `audioknigi/providers/adapters.py`, `registry.py`: регистрация новых источников.
- `audioknigi/services/book_analysis_service.py`: анализ книг через общий headless сервис с той же моделью Book/Track.
- `audioknigi/qt/mixins/search.py`: источники в фильтре поиска строятся по реестру; Akniga исключена из поиска, поскольку сейчас поддерживает только прямые ссылки.
- В `requirements.txt` и `requirements-release.txt` добавлен BeautifulSoup4 (и pin soupsieve для релиза); новому коду не нужны orjson, loguru, webview или дополнительные исполняемые файлы из AudioBookPlayer.
- Для прямых MP3-файлов границы глав не задаются, чтобы не обрывать запись по округлённой приблизительной длительности. Метаданные длительности сохраняются.
- `audioknigi/download/network.py`: два удаления временных файлов переведены на существующий Windows-safe `unlink_with_retry` (тестовый контракт и WinError 32).

## Проверки

- `python -m pytest -q tests/unit`: **62 passed**.
- Отдельные офлайн-фикстуры новых источников: распознавание доменов, JSON/GraphQL/XSPlayer, ограниченные книги, LibriVox и отмена.
- В интеграционных тестах без Qt selftest прошло 141 тестов до остановки на унаследованном архивном localization audit. Полный набор тестов НЕ проходит (существующее имя теста с `audit/phase`, отсутствие PySide6 в Linux и прежние новые HLS-строки без локализаций).
- Синтаксис Python проверен, исходный архив можно распаковать.
- Реальные загрузки из всех четырёх новых сайтов и запуск Windows/NVDA/JAWS **не проверены**; страницы и API могут измениться. Это исходники, не готовый исполняемый файл.

## Использование

1. Создайте резервную копию рабочей программы, не заменяйте стабильный EXE.
2. Установите зависимости из requirements (в том числе BeautifulSoup4). Для Windows-сборки используйте обновлённый `requirements-release.txt`.
3. Начните с прямой ссылки на книгу нового источника; проверьте названия и порядок глав, затем попробуйте маленькую книгу, которую разрешено скачивать.
4. Если не получилось — приложите журнал ошибок, **не** прикладывайте приватные ссылки, токены доступа или личные пароли.

Вопросы авторских прав и условий каждого сайта остаются в силе. Не используйте проект для обхода ограничений на скачивание.
