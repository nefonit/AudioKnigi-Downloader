# AudioKnigi Downloader — V16 (экспериментальная версия)

База: проверенный проект V15. Обновление ограничено адаптерами и диагностикой, загрузчик Akniga/HLS не изменялся.

## Что изменилось

1. `uknig.com`: описание берётся только из `div.description` на странице книги, с учётом `<p>` и `<br>`. Пример для проверки: `https://uknig.com/books/678270`.
2. `yakniga.org`: при анализе GraphQL-полученные главы больше не запускают дополнительный сетевой FFprobe по всем отсутствующим длительностям. Продолжительности, указанные в GraphQL, сохраняются; если значение отсутствует, оно остаётся неизвестным до дальнейшей обработки/скачивания. Выбор книги, главы и скачивание не меняются.
3. LibriVox: сначала поиск в коллекции `librivoxaudio` Archive.org, затем при пустой выдаче — официальный LibriVox API по названию и автору. Книги с безопасной ссылкой на Archive.org можно анализировать и скачивать по существующему механизму.
4. Диагностика поиска: поскольку общий стандартный запрос `Поттер` заведомо может быть пустым для каталога свободных записей, для LibriVox он меняется только в диагностике на `Sherlock Holmes` и прямо помечается в отчёте. Обычный поиск ничего не подменяет.

## Проверки и ограничения

- `610 passed, 1 deselected` по модульным и профильным интеграционным тестам (без исторического аудита).
- Один исторический аудит локализации не проходит с двумя известными проверками и в самой исходной V15.
- Нет живой Windows-проверки Yakniga/Uknig/LibriVox, запуска PySide6 и NVDA/JAWS.
- Интернет и состояние сайтов могут изменяться. Для LibriVox рекомендуем проверять на `Sherlock Holmes`, `Jules Verne` (англоязычные названия). `Поттер` может не возвращать записей по причинам авторского права и ограничений коллекции.
- Для нового каталога LibriVox используется официальный `https://librivox.org/api/feed/audiobooks` по правилам сервиса; запросы не отправляются чаще необходимого.

## Проверка на Windows

1. Проверить описание `https://uknig.com/books/678270` после анализа.
2. Проверить время анализа `https://yakniga.org/rouling-dzhoan/garri-potter-i-dary-smerti` (с Cloudflare One в сети, где он необходим). Если длительность отдельной главы неизвестна, она может быть определена позже.
3. В диагностике поиска посмотреть источник `archive.org`: теперь виден тестовый запрос `Sherlock Holmes`. Затем выполнить самостоятельный поиск `Sherlock Holmes` и попробовать открыть найденную запись.
