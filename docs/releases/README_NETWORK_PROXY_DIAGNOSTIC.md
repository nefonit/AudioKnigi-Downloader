# Эксперимент: диагностика сети и пользовательский прокси

## Настройка
В «Настройки → Загрузка и сеть» добавлены поле «Прокси (необязательно)» и кнопка «Проверить подключение ко всем источникам». Пример адреса прокси: `http://127.0.0.1:8080` или `socks5h://127.0.0.1:1080`. Поле можно оставить пустым. Поддерживаются **только прокси без логина и пароля**; приложение отклоняет адреса с учётными данными и не сохраняет их в настройках. Само приложение **не поднимает внешний прокси или VPN**: он должен существовать и быть доступен заранее.

Прокси используется для поиска, сетевых запросов, Playwright, FFmpeg/FFprobe и параллельной HLS-загрузки через внутренний HTTP-мост на `127.0.0.1`. При указании внешнего HTTP или SOCKS5-прокси доменное имя сайта разрешается на стороне этого прокси. Без внешнего прокси в режиме «Автоматически» Python-запросы, Playwright и FFmpeg используют единый локальный DNS/TCP-маршрутизатор; «Только Cloudflare» не использует системный DNS для публичных имён. После смены прокси настройки действуют на новые операции; текущие загрузки следует закончить или отменить перед изменением.

## Ограничения
Cloudflare DoH — только DNS и **не является** альтернативой VPN/WARP. Успешный DNS при тайм-ауте TCP, как в предоставленных пользователем диагностических отчётах для akniga.org и uknig.com, сам по себе не позволяет восстановить связь. Подключение через прокси работает только при наличии отдельно запущенного, доступного и разрешённого прокси-сервера. Не пробует в обход явного пользовательского прокси и не подменяет его прямым соединением при сбое.

Фоновая проверка использует HTTP GET. Ручная подробная проверка выполняет отдельное HTTPS HEAD-подключение и сообщает источник DNS, IP попытки, время DNS/TCP/TLS и HTTP-код. HTTP 403/429/503 означает, что сервер ответил, но контент может быть недоступен. Проверка сама не скачивает книги. Настройка не гарантирует доступность источников, которые находятся в другой стране или ограничены провайдером. Реальные проверки Windows/Edge/FFmpeg/SOCKS5/ NVDA/JAWS не проводились в этой среде.
