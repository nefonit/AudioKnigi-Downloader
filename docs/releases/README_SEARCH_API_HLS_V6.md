# V6 — стабильность поискового API и защита HLS

Экспериментальное дополнение к AudioKnigi Downloader 4.12.42 V5. Основная версия приложения не повышается; исходный код, не Windows EXE.

## Что изменилось

1. **Yakniga /graphql**: поисковые GraphQL-запросы и запросы сведений о книге являются операциями чтения. Для них задан ограниченный сетевой тайм-аут (connect 3 c, read 5 c), и ровно одна повторная попытка после `ConnectTimeout`, `ReadTimeout` или `ProxyError`. Мутации, ошибки HTTP, JSON и структуры данных повторять нельзя; отмена пользователя прерывает ожидание и попытку. Это не VPN и не способ устранить блокировку TCP.
2. **Диагностика реального поиска**: отчёт сообщает тип поискового endpoint (для Yakniga — `GraphQL POST`, для Akniga/Izib — `Каталог GET`). Отказ внутреннего DNS-моста в AUTO, когда пользовательский прокси отключён, описывается как «Внутренний DNS-мост: HTTPS-соединение до сайта не установлено», а не как ошибка *пользовательского* прокси. HTTP-коды и изменения формата ответа API обозначаются отдельно. В журнал диагностики не попадают полные адреса запросов, токены, cookies или поисковые строки.
3. **HLS**: если ожидаемая длительность известна и у движка есть анализатор длительности, создаваемый FFmpeg временный MP3 проверяется *до замены* итогового файла. Недостача более 1% либо 8 секунд — ошибка; уже имеющийся файл сохраняется. Для параллельного HLS остаётся возможность безопасно перейти к обычной загрузке FFmpeg. Если определить длительность нельзя, работает прежняя проверка таймкодов на следующем этапе. Проверка не гарантирует целостность каждой секунды аудио; она исключает лишь явно короткий результат.

Все восемь источников, настройки DNS, выборочный пользовательский прокси, интерфейс и остальные функции не изменены.

## Проверка на Windows

1. Сохраните резервную копию V5 и настройки/папку аудиокниг.
2. Если зависимости ещё не установлены, установите их из штатного файла проекта в той же среде Python, из которой запускается приложение.
3. Включите Cloudflare One. В поиске используйте «Шерлок Холмс» и повторите проверку поиска для yakniga.org и akniga.org, обращая внимание на пометки `GraphQL POST` и `Каталог GET`.
4. Выключите Cloudflare One, повторите диагностику. Для Yakniga может остаться недоступность TCP; новая версия должна показывать «Внутренний DNS-мост» вместо ошибки пользовательского прокси, если выбран AUTO и пользовательский прокси отключён.
5. При разрешённых к сохранению аудиоматериалах проверьте короткую главу Akniga. Если поток прервётся раньше конца, программа не должна заменять уже существующий MP3 неполной копией.
