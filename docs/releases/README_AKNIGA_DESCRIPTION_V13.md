# V13 — корректный выбор описания книги Akniga

База: AudioKnigi Downloader V12. V12 остаётся без изменений.

## Исправлено

На некоторых страницах Akniga рядом с аннотацией книги расположены блоки
«Другие озвучки», сведения о серии или подборке. Раньше парсер мог принять
первый длинный блок `.description__article-main` за аннотацию даже без
заголовка «Описание».

Теперь порядок извлечения описания:

1. Блок `.description__article-main` с заголовком «Описание» внутри.
2. Блок непосредственно после отдельного заголовка «Описание».
3. Семантические селекторы описания, затем текст после отдельного заголовка.
4. Старый одиночный блок без заголовка (для совместимости).
5. Метаданные страницы с удалением SEO-вступления.

Сведения о других озвучках, серии и подборках не используются вместо
описания. Программа не подставляет заранее сохранённое описание определённой
книги — текст читается с фактической страницы.

## Проверка на Windows

1. Включить Cloudflare One, если без него Akniga недоступна.
2. Открыть `https://akniga.org/lavkraft-govard-uzhas-danvicha` и заново нажать
   «Анализировать», чтобы загрузить свежие данные.
3. Описание на странице сайта начинается с «Второго февраля 1913 года у
   Лавинии Уэйтли родился сын Уилбер». Убедиться, что в программе описание
   начинается так же, а не с блока серии или других озвучек.
4. Для контроля проверить `https://akniga.org/kozhin-oleg-snegurochka`:
   описание должно начинаться с «Рассказ-победитель первого в истории DARKER…».

## Тесты и ограничения

Автономные регрессионные тесты воспроизводят ситуацию с несколькими блоками
на странице и ранее падали на V12. Настоящая HTML-страница «Ужас Данвича» не
была доступна для сохранения в тестовой среде; требуется проверка на Windows.

Код загрузки HLS, DNS, интерфейс и остальные источники не изменены.
