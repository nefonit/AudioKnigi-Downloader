# V15: Исправление пустого описания yakniga.org

## Проблема

GraphQL-запрос `getBook` иногда возвращает пустое поле `description`, хотя HTML-страница произведения содержит полную аннотацию в `div.page__description` (в том числе с CSS-классом `page__description-hide`). Раньше анализ книги в таком случае возвращал пустое описание.

## Исправление

- При непустом описании из GraphQL оно используется без дополнительных HTTP-запросов.
- Если описание отсутствует, приложение делает один GET страницы книги на yakniga.org (ограниченный timeout 3 с подключения + 7 с ответа) и читает *только* `div.page__description`.
- Соседние элементы, серии, отзывы, рекламные метатеги в описание не добавляются.
- Ошибка GET (в том числе тайм-аут и HTTP 403) не ломает уже полученные заголовок, главы и плеер; описание останется пустым.
- Отмена пользователем остаётся отменой. Книги с ограничениями не вызывают дополнительную загрузку HTML.
- Другие восемь источников, DNS, загрузка файлов и HLS не изменены.

## Проверка Windows

1. Включите Cloudflare One, если без него yakniga.org недоступен.
2. В программе проанализируйте `https://yakniga.org/rouling-dzhoan/garri-potter-i-dary-smerti`.
3. Поле описания должно начинаться с «Лето перед последним курсом обучения Гарри в Хогвартсе.» и заканчиваться словами «...вместе с друзьями отправляется на поиски.»
4. Убедитесь, что название, исполнитель, главы и скачивание остались доступны.

## Статус проверки

547 локальных автономных тестов прошли. Точная HTML-структура воспроизведена из предоставленного примера. Живое открытие yakniga.org через пользовательскую Windows-сеть, PySide6, NVDA/JAWS не проверялось.
