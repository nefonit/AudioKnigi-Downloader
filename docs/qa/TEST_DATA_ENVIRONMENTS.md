# QA окружения, тестовые данные и воспроизводимость

AudioKnigi Downloader 4.12.42 | QA Baseline v1.0 | 2026-10-15

## Базовое окружение

| Среда | Использование | Статус |
|---|---|---|
| Windows x64, Python 3.11 | Минимальная поддерживаемая версия, тесты и EXE | Нужен релизный запуск |
| Windows CI Python 3.14.7 | Целевая сборка/модульные проверки | Workflow существует; не равно acceptance |
| PySide6 + Qt Multimedia | GUI и аудиоплеер | Проверять на Windows |
| Microsoft Edge, Playwright fallback | Динамические источники | Проверять актуальный Edge |
| FFmpeg + FFprobe | Длительности, MP3, нормализация | Фиксировать версии и пути |
| NVDA (зафиксировать версию) | Озвучивание, фокус, роли | Not Run |
| JAWS (зафиксировать версию) | Озвучивание, фокус, роли | Not Run |

## Обязательные тестовые данные

- MP3 (CBR/VBR), WAV, AAC/Opus (только где поддерживаются исходники), короткий и длинный файл, разные каналы и битрейты.
- Книга с одной главой, с несколькими главами, общий источник с таймкодами, отсутствующие/испорченные таймкоды и отсутствующая последняя длительность.
- HTTP stub со стандартным ответом, Range 206, игнорируемым Range, 404/410, 503, redirection, partial EOF, slow stream, ответом без Content-Length.
- Настройки старого профиля (строковое false, migration marker, 125% scale), новый пустой профиль и синтаксически битый JSON.
- Очередь: pending/interrupted/needs_analysis/completed, некорректная запись и большая cover_cache.
- Диагностика: искусственные Authorization Bearer/Basic, Cookie, приватные Windows/UNC paths и сообщения с переносами строк.
- Локали RU/UK/EN/DE; отдельная аудио/клавиатурная матрица NVDA и JAWS.

## Правила тестовых файлов

Использовать собственные или разрешённые короткие медиа для автоматических тестов и не прикладывать реальные cookie/секреты к баг-репортам. Для внешних источников не обещать неизменность URL и времени ответа; хранить timestamp и источник. Для тестов удаления/аварийного завершения использовать отдельный временный профиль и резервную копию.
