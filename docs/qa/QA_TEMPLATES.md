## Example statuses

- Not Run: кейс спроектирован, но не исполнялся для данной версии.
- Pass: шаги исполнены, результат совпал с ожидаемым и есть свидетельство.
- Fail: фактическое поведение не совпало, есть bug ID.
- Blocked: недоступна среда/тестовые данные/сторонний ресурс.
- N/A: неприменимо к данному варианту конфигурации, указана причина.
